This folder holds Ghost-era experiments and helper scripts that are no longer part
of the live Astro/EmDash site, but may still be useful as references.

Archived here on 2026-04-25:

- `pages/gallery-edge.astro`: hidden Ghost Edge-style gallery experiment
- `pages/gallery-edge-exact.astro`: more exact Ghost Edge replication experiment
- `scripts/export-ghost-to-wxr.mjs`: one-off Ghost export helper for import testing

These were removed from active routes/tooling to reduce clutter while keeping a
recoverable reference if needed later.
